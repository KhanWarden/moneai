### Частые вопросы

**Нужен ли аккаунт или интернет?**
Нет. Приложение работает полностью офлайн, без регистрации.

**Где хранятся мои данные? Вы их видите?**
Только на вашем устройстве. У приложения нет серверов, аналитики и рекламы, я не имею доступа к вашим данным. Подробнее в [Политике конфиденциальности](PRIVACY_POLICY.md#русский).

**Как перенести данные на новый телефон?**
Сделайте экспорт или резервную копию (CSV или JSON) в настройках приложения, сохраните файл в «Файлы» или передайте через AirDrop, затем импортируйте его на новом устройстве.

**Я удалил приложение. Можно восстановить данные?**
Я не храню ваши данные, поэтому восстановить их могу только из вашей собственной резервной копии (файл экспорта или копия устройства). Рекомендую регулярно делать экспорт.

**Не приходят напоминания о платежах.**
Проверьте, что уведомления для moneai разрешены: Настройки iOS → Уведомления → moneai.

**Не сохраняется местоположение у транзакций.**
Включите опцию «Сохранять координаты» в настройках приложения и разрешите доступ к геопозиции: Настройки iOS → Конфиденциальность → Службы геолокации → moneai → «При использовании».

**Face ID / Touch ID не работает.**
Убедитесь, что биометрия настроена в iOS и что moneai разрешён доступ к Face ID: Настройки iOS → moneai → Face ID.

### FAQ

**Do I need an account or internet connection?**
No. The app works fully offline with no sign-up.

**Where is my data stored? Can you see it?**
On your device only. The app has no servers, analytics or ads, and I have no access to your data. See the [Privacy Policy](PRIVACY_POLICY.md#english) for details.

**How do I move my data to a new phone?**
Export your data or create a backup (CSV or JSON) in the app's settings, save the file to Files or send it via AirDrop, then import it on the new device.

**I deleted the app. Can I get my data back?**
I don't store your data, so it can only be restored from your own backup (an export file or a device backup). Exporting regularly is recommended.

**Bill reminders don't show up.**
Make sure notifications are allowed for moneai: iOS Settings → Notifications → moneai.

**Location isn't saved with transactions.**
Turn on "Save Location" in the app's settings and allow location access: iOS Settings → Privacy & Security → Location Services → moneai → "While Using the App".

**Face ID / Touch ID doesn't work.**
Make sure biometrics are set up in iOS and moneai is allowed to use Face ID: iOS Settings → moneai → Face ID.
